# 学习通批量工作台 0.3.1

## 安装与登录

下载 Windows 程序包，完整解压后双击 `学习通工作台.exe`。EXE 与 `_internal` 保持在同一目录。

在“设置”填写学习通账号，点击“登录并加载课程”。AI 地址默认为 `https://api.deepseek.com`，模型默认为 `deepseek-flash`，填写自己的 API Key。视频与答题默认并发分别为 4 和 2。

## 添加任务

1. 在“任务”页面点击“添加任务”。
2. 勾选课程选择整门课程，也可展开课程选择部分章节；支持多门课程。
3. 选择视频、AI 答题或两者。
4. 选择答题完成后“保存草稿，等待审核”或“自动交卷完整测验”。
5. 点击“添加并开始”。运行中可以追加其他课程任务。

添加时重新读取课程章节及平台任务列表。视频从平台记录的播放进度继续；答题读取最新题目，复用仍然有效的本地答案。

## 当前任务与历史记录

任务页面一次显示一张任务表，通过筛选切换“当前任务”“历史记录”或“全部任务”，也可按视频、答题等类型筛选。

点击任务行或复选框勾选；按住 Shift 可以连续勾选。“全选 / 清空”只作用于当前显示的记录，右侧显示已选数量。

- **取消已选**：取消勾选任务的本轮执行。当前请求返回后结束，结果保留在历史记录及答题页面，其他任务继续。
- **重新加入**：勾选历史任务后使用。先读取平台最新进度，已完成的直接更新状态，未完成的继续执行。
- **查看详情**：查看一项任务的执行原因与平台状态。

执行状态统一为读取进度、等待执行、执行中、正在取消、已取消、失败、未开放和已完成。任务控制使用“取消已选”和“重新加入”。

## 题目处理

“答题 → 题目处理”集中显示跨课程、跨章节的题目。可筛选需处理、全部、正常、异常或未答题。

- **AI 重做**：只重做勾选题目，重新请求 AI 并保留历史答案。
- **查看 / 修改**：勾选一道题后打开详情；单选填 `A`，多选填 `AC`，判断填 `true` 或 `false`，点击“保存修改”。

人工修改与 AI 重做的结果先保存在本地，所在测验标为待同步。筛选异常题后全选，可一次重做多个课程和章节的异常题。

## 测验提交

“答题 → 测验提交”按整份测验汇总答案。章节是课程内容分组，一章可能包含多份测验。

| 操作 | 作用范围与逻辑 |
| --- | --- |
| 同步草稿 | 将勾选测验的正常答案同步到平台草稿；只处理本地有更新或上次同步失败的测验 |
| 提交测验 | 提交勾选且答案完整的测验；异常测验保留待处理，其他测验继续 |
| 更多 → 读取平台状态 | 检查勾选测验的完成情况，适合处理交卷结果待确认的记录 |
| 更多 → 含未答题交卷 | 本次按整份测验提交，异常和未答题留空 |

可以按待同步、可提交、有异常、待确认或已交卷筛选。批量交卷时筛选“可提交”，全选后点击“提交测验”。

无勾选时不执行批量操作。“题目处理”和“测验提交”各自使用当前表的勾选项。

## 草稿、交卷与异常

自动答题结束后默认同步草稿，未解决的题目继续保留。启用自动交卷时，答案完整的测验直接提交，其他测验保存草稿。

草稿“已同步”表示平台保存成功；“待同步”表示本地有修改或同步失败。提交结果不明确时显示“待确认”，可从“更多”读取平台状态。

单题失败后保留原因并继续下一题，单份测验失败后继续后续任务。AI 配置、额度或持续限流问题结束当前答题批次，视频继续；修改设置后从历史记录重新加入。

“操作记录”按需查看同步、交卷与 AI 重做的结果，不切换当前工作页面。

## 设置与升级

设置自动保存。账号、Cookie、任务、答案及历史沿用 `%LOCALAPPDATA%\ChaoxingDesktop`。

升级时关闭程序，替换程序目录，继续使用同一数据目录。运行逻辑见 [工作流程](WORKFLOWS.md)，术语定义见 [用语表](../GLOSSARY.md)，源码构建见 [开发说明](DEVELOPMENT.md)。
