# 界面与工作流程

## 页面

| 页面 | 主要内容 | 操作 |
| --- | --- | --- |
| 任务 | 当前任务或历史记录，一次显示一张任务表 | 添加任务、取消已选、历史任务重新加入、删除列表项 |
| 答题 · 题目处理 | 跨课程题目表，可筛选异常与正常题 | 修改答案、AI 重做已选题、删除列表项 |
| 答题 · 测验提交 | 跨课程测验表，可筛选待同步、可提交与待确认 | 同步草稿、提交测验、读取平台状态、删除列表项 |
| 设置 | 账号、AI 连接及运行参数 | 登录、自动保存设置 |

课程与章节选择放在“添加任务”窗口，题目详情和批量操作记录按需打开。

## 选择范围

所有批量操作只使用当前表内勾选项。“全选”只选择当前筛选结果；切换筛选会清除不再显示的勾选。无勾选时不执行操作。

题目级操作为修改与 AI 重做；测验级操作为同步草稿与整份交卷。

表头保留“全选”，列表外部使用“删除”。删除按各表勾选范围移出列表项，并保留完整测验与已有答案；任务列表删除会先取消执行，答题页删除仅整理对应列表。删除状态持久保存，后台进度更新不会重新插入。主动重新添加章节或将历史任务重新加入时恢复对应显示。

## 执行

1. 选择多门课程和章节，添加视频、答题或两种任务。
2. 每次添加或重新加入，读取平台任务列表；视频读取播放进度，测验读取最新题目，复用本地仍有效的答案。
3. 视频与答题分别排队，互不等待；单题或单个任务失败后保留结果，继续其他任务。
4. 答题默认自动同步草稿；可选择完整且无异常的测验自动交卷。
5. 人工修改与 AI 重做保留历史，结果待审核。仅有更新或同步失败的测验可以再次同步草稿。
6. 取消只影响所选任务。已发请求返回后完成取消，已有结果保留在历史及答题页面。
7. 历史任务只有主动重新加入才执行；重新加入先查询平台进度，已完成的内容直接标为完成。

## 连接异常

API 配置或额度故障结束当前答题批次并保留结果，视频继续。修正设置后，从历史中重新加入答题任务。

## 数据

账号、设置与历史数据沿用 `%LOCALAPPDATA%\ChaoxingDesktop`。
